== Introduction

This repository contains official specifications and directives maintained by
the Enosema Foundation (ES). The Enosema Foundation is the premier non-profit standardization
organization for terminology standardization and terminology related processes
such as management.

The specifications include:

2501:: *Terminology management principles and methods* -- Specification for effective management of terminology resources including creation, collection, maintenance, and presentation
2504:: *Multilingual terminology management* -- Principles and methods for managing terminology across multiple languages and cultures
2507:: *Concept relationships* -- Abstract model and implementation guidance for defining and managing relationships between concepts

The directives include:

101:: *Standardization and publication* -- Directive on the ES standardization and publication processes
102:: *Standard document requirements* -- Directive on requirements for ES standard documents
103:: *Patent policy* -- Directive on the ES patent policy
104:: *Guidelines for the implementation of the patent policy* -- Directive providing guidelines for the implementation of the ES patent policy
105:: *Intellectual property rights policy* -- Directive on the ES intellectual property rights policy

The specifications and directives are written in Metanorma to generate standardized
documentation in multiple formats.

== Building documentation

This repository uses Metanorma to build standardized documentation.

=== Installing build tools

See https://www.metanorma.org/install/ for detailed installation instructions.


=== Building locally

If you have Metanorma installed locally, run:

[source,sh]
----
metanorma site generate
----

=== Building with Docker

If you prefer using Docker, run:

[source,sh]
----
docker run -v "$(pwd)":/metanorma -w /metanorma -it metanorma/mn metanorma site generate
----

== Generated Formats

The build process generates documentation in multiple formats:

* HTML -- Web-friendly format with navigation
* PDF -- Print-ready format
* XML -- Machine-readable format
* RXL -- Relaton XML bibliographic format
